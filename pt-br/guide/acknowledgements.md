# Agradecimentos

Este SDK existe por causa do trabalho de longa data da comunidade
[ps2dev](https://github.com/ps2dev) no desenvolvimento homebrew de PS2.

O [`sdk-core`](https://github.com/ps2build/sdk-core) é baseado
em código originalmente desenvolvido pelo projeto
[ps2dev/ps2sdk](https://github.com/ps2dev/ps2sdk) e seus contribuidores.
O [`sdk-world`](https://github.com/ps2build/sdk-world) se apoia
no [ps2dev/ps2sdk-ports](https://github.com/ps2dev/ps2sdk-ports) e em
vários ports independentes da comunidade - veja a página de
[pacotes disponíveis](/pt-br/guide/available-packages) para saber
exatamente de onde vem o código-fonte de cada um.

**Este projeto não é afiliado, endossado, ou oficialmente conectado ao
ps2sdk, ps2sdk-ports, ps2dev, ou a nenhum de seus mantenedores, de
forma alguma.** É um fork independente e uma reconstrução de pacotes -
se algo está quebrado aqui, é problema nosso consertar, não deles. Por
favor não abra issues deste projeto em nenhum repositório upstream.
