17/*
18 NOTE: These functions will work with the MCMAN/MCSERV or XMCMAN/XMCSERV
19 modules stored in rom0. The library will automatically detect which
20 module is used and will use the appropriate RPC commands accordingly.
21
22 NOTE: These functions seem to work for both psx and ps2 memcards
23
24 to use memcards:
25 1) first load modules (sio2man then mcman/mcserv)
26 2) call mcInit(MC_TYPE)
27 3) use mcGetInfo() to see if memcards are connected
28 4) use mcSync to check that the function has finished
29
30 all mc* functions except mcInit() are asynchronous and require mcSync()
31 usage to test when they are done
32*/
