initializes both the serial port comunication and the EE_SIO custom stream to print data trough it

Parameters
baudratebaudrate of the EE SIO. Unlike the BIOS sio_init() routine, we always base the baud rate on the CPU clock. 38400 is the recommended value
lcr_uepspassed as is, so you'll need to use the SIO_LCR_* register values. You can pass 0 for all of the lcr_* params to get the standard 8N1 setting (8 data bits, no parity checking, 1 stop bit).
lcr_upenpassed as is, so you'll need to use the SIO_LCR_* register values. You can pass 0 for all of the lcr_* params to get the standard 8N1 setting (8 data bits, no parity checking, 1 stop bit).
lcr_usblpassed as is, so you'll need to use the SIO_LCR_* register values. You can pass 0 for all of the lcr_* params to get the standard 8N1 setting (8 data bits, no parity checking, 1 stop bit).
lcr_umodepassed as is, so you'll need to use the SIO_LCR_* register values. You can pass 0 for all of the lcr_* params to get the standard 8N1 setting (8 data bits, no parity checking, 1 stop bit).
hook_stdoutwether to also hook EE SIO into stdout
Returns
0 on success, nonzero on error. see EE_SIO_START_RETCODES enum for further details

EE_SIO_START_RETCODES, https://en.cppreference.com/w/c/io/setvbuf
