51 /**************************************************************************
52 *
53 * @struct:
54 * T1_EncodingRec
55 *
56 * @description:
57 * A structure modeling a custom encoding.
58 *
59 * @fields:
60 * num_chars ::
61 * The number of character codes in the encoding. Usually 256.
62 *
63 * code_first ::
64 * The lowest valid character code in the encoding.
65 *
66 * code_last ::
67 * The highest valid character code in the encoding + 1. When equal to
68 * code_first there are no valid character codes.
69 *
70 * char_index ::
71 * An array of corresponding glyph indices.
72 *
73 * char_name ::
74 * An array of corresponding glyph names.
75 */
