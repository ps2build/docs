Detailed Description

PS2 audio library: PCM streaming and preloaded ADPCM sounds on mixer channels.

Every function here works on one default context, created by audio_init() and released by audio_shutdown(). audio_core.h has the same functions on an explicit context.

Return values: a value >= 0 is success (some functions return a count or a channel number). A failure is the negated error code, for example -AUDIO_ERR_INVALID_ARGUMENT. See Concepts for how the parts fit together.
