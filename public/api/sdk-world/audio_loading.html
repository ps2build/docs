Loading the driver

The EE library talks to audio.irx, which the application loads before calling audio_init(). It needs libsd.irx loaded first. The library does not load modules itself, because a library archive cannot carry a module and an application may already have loaded them.

With ps2build, embed the modules in the program and load them from memory:

targets:
- name: game
type: ee
sources: [main.c]
libs: [audio]
embed_irx: [libsd, audio]
#include "libsd_irx.h"
#include "audio_irx.h"
SifInitRpc(0);
sbv_patch_enable_lmb();
SifExecModuleBuffer(libsd_irx, size_libsd_irx, 0, NULL, NULL);
SifExecModuleBuffer(audio_irx, size_audio_irx, 0, NULL, NULL);
audio_init();
