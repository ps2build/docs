Detailed Description

Sounds on mixer channels and PCM streaming for the EE, with an IOP driver on the SPU2.

The library has two parts: an IOP module, audio.irx, that drives the SPU2, and an EE library, libaudio.a, that talks to it. The functions are in audio.h, and audio_core.h has the same functions on an explicit context. Concepts describes how the parts fit together, and Sound files (.adp) the sound file format. Code written against audsrv can use the audsrv-compat package instead; see Moving from audsrv to audio.
