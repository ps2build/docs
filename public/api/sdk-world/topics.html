 siocookie
 smbmanImports and definitions for ps2ip. Real, verbatim upstream header (iop/tcpip/tcpip/include/ps2ip.h) - declares the IOP-side ps2ip.irx module's real exported symbols (lwip_, ps2ip_, pbuf_, netif_, tcpip_ prefixed - real dynamic IRX imports, resolved by the IOP kernel at module-load time via imports.lst, not by ps2build/iopfixup at build time) for a consumer like smbman that gets loaded alongside a running ps2ip.irx. sdk-core does not yet ship a real ps2ip.irx (only the EE-side lwip build, core/ps2ip, and the SIF-RPC-based core/ps2ips client - a genuinely different, third architecture from this IOP-dynamic-import one) - deliberately deferred per direct decision, so this package builds real and clean but needs a real ps2ip.irx present at runtime to actually load. Placed here (not core/common) since smbman is its only consumer right now; move to a shared location if/when the real IOP tcpip.irx port lands and other IOP-dynamic-import consumers show up
