Detailed Description

PCM playback for music and video audio.

One stream per context. Data is queued in the format given to audio_stream_start() and the library converts it to the 48 kHz stereo 16-bit layout the SPU2 plays. All byte counts are in the source format. A stream that runs out of data plays silence and continues when more arrives; that is not an error.

Parameters

◆ audio_stream_set_low_data_callback()

int audio_stream_set_low_data_callback ( int32_t threshold_bytes,
audio_low_data_fn callback,
void * user )

Registers a function called when the queued data falls to a threshold.

The callback runs on a thread owned by the library, once each time the queue drains to the threshold. It runs again only after the level has risen above the threshold. Registering does not call it for a level that is already low. The callback may queue data; it must not end or restart the stream. The threshold is kept when the stream is restarted.

Parameters
threshold_bytes0 up to the capacity of the stream, in source bytes; 0 calls back only when empty.
callbackThe function, or NULL to unregister.
userPassed to the callback unchanged.
Returns
AUDIO_OK, -AUDIO_ERR_STREAM_NOT_STARTED, -AUDIO_ERR_INVALID_ARGUMENT or -AUDIO_ERR_NOT_INITIALIZED.

Blocks until at least byte_count bytes can be queued.

timeout_msMilliseconds to wait: 0 polls once, -1 waits forever.
Returns
