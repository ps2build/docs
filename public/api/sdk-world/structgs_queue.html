Detailed Description

gsQueue Structure This is the structure for gsKit draw queues.

By default, gsKit creates two of these for you. It creates Os_Queue (Oneshot Objects), and Per_Queue. (Persistent Objects)

You can create your own gsQueue objects and load them with prepacked GIF/VIF chains!
