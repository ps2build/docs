◆ audsrv_ch_play_adpcm()

int audsrv_ch_play_adpcm ( int ch,
audsrv_adpcm_t * adpcm )

Plays a loaded sample on channel ch (0-23), replacing what is playing there. Any other value of ch plays it on the first free channel.

Parameters
chThe channel, or -1 for any free channel.
adpcmThe sample.
Returns
The channel number, or a negative error (-AUDSRV_ERR_NO_MORE_CHANNELS when none is free).
