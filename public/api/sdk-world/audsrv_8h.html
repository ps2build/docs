Detailed Description

audsrv source compatibility for the audio library.

Code written against the audsrv API builds and runs on top of audio without changes. Streaming maps onto the audio stream, samples onto audio sounds and channels. CD audio is not supported and reports AUDSRV_ERR_NO_DISC. Moving from audsrv to audio lists each call with its audio equivalent and the differences.
