Detailed Description

The audio library on an explicit context instead of the default one.

Each audio_ctx_* function matches the audio.h function of the same name without the ctx_ part, for example audio_ctx_stream_start() and audio_stream_start(). Parameters, results and errors are as documented there. A NULL context returns -AUDIO_ERR_NOT_INITIALIZED, except audio_ctx_get_version().

◆ audio_context_create()

int audio_context_create ( const audio_context_options_t * options,
audio_context_t ** context_out )

Connects to the audio driver. audio.irx must already be loaded.

Parameters
optionsOptions, or NULL for the defaults.
[out]context_outReceives the context, or NULL on failure.
Returns
AUDIO_OK, -AUDIO_ERR_ALREADY_INITIALIZED, -AUDIO_ERR_RPC_FAILED, -AUDIO_ERR_OUT_OF_MEMORY or -AUDIO_ERR_INVALID_ARGUMENT.
Note
The driver serves one context at a time, so a second create fails while one exists.

◆ audio_context_destroy()

int audio_context_destroy ( audio_context_t * context)

Stops everything, frees every sound and releases the context.

Calls in flight on other threads finish first (up to half a second) and waiters return -AUDIO_ERR_INTERRUPTED. New calls on the context fail. Stop the threads that use the context before destroying it.

Parameters
contextThe context. NULL is accepted.
Returns
AUDIO_OK.
