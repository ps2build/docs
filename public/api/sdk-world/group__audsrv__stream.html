◆ audsrv_on_fillbuf()

int audsrv_on_fillbuf ( int amount,
audsrv_callback_t cb,
void * arg )

Calls cb(arg) when at least amount bytes of stream space are free, once each time the queue drains to that point. A NULL cb unregisters. The stream must be started. Returns 0, or -AUDSRV_ERR_ARGS if amount is larger than the stream buffer.

Parameters
amountFree space that triggers the call.
cbThe function, or NULL.
argPassed to cb.
Returns
0 or a negative error.
