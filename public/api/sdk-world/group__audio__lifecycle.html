Connects to the audio driver. audio.irx must already be loaded.

Returns
AUDIO_OK, -AUDIO_ERR_ALREADY_INITIALIZED, -AUDIO_ERR_RPC_FAILED or -AUDIO_ERR_OUT_OF_MEMORY.
Note

◆ audio_shutdown()

int audio_shutdown ( void )

Stops everything, frees every sound and disconnects. Safe to call when not initialized.

Threads blocked in audio_stream_wait_until_writable() return -AUDIO_ERR_INTERRUPTED. Stop the threads that use the library before calling this.

Returns
AUDIO_OK.
