Detailed Description

The audio library on an explicit context object.

Every function in audio.h has a twin here, prefixed audio_ctx_, that takes the context as its first argument and behaves the same. The audio.h functions are one-line wrappers over one default context. A C++ wrapper can own a context per object and release it in a destructor.
