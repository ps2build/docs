# Agradecimientos

Este SDK existe gracias al trabajo de larga duración de la comunidad
[ps2dev](https://github.com/ps2dev) en el desarrollo homebrew de PS2.

[`sdk-core`](https://github.com/ps2build/sdk-core) está basado
en código originalmente desarrollado por el proyecto
[ps2dev/ps2sdk](https://github.com/ps2dev/ps2sdk) y sus contribuidores.
[`sdk-world`](https://github.com/ps2build/sdk-world) se apoya en
[ps2dev/ps2sdk-ports](https://github.com/ps2dev/ps2sdk-ports) y en
varios ports comunitarios independientes - consulta la página de
[paquetes disponibles](/es/guide/available-packages) para saber
exactamente de dónde viene el código fuente de cada uno.

**Este proyecto no está afiliado con, respaldado por, ni conectado
oficialmente a ps2sdk, ps2sdk-ports, ps2dev, ni ninguno de sus
mantenedores, de ninguna forma.** Es un fork independiente y una
reconstrucción de paquetes - si algo está roto aquí, es nuestro
arreglarlo, no de ellos. Por favor no reportes problemas de este
proyecto en ningún repositorio upstream.
