# Referencia de la API

La referencia generada de `sdk-core` y `sdk-world` estará disponible pronto.

Cubrirá todas las cabeceras y funciones públicas de ambos SDK. Mientras tanto, las cabeceras de los repositorios [sdk-core](https://github.com/ps2build/sdk-core) y [sdk-world](https://github.com/ps2build/sdk-world) son la fuente de referencia, y la [guía](/es/guide/getting-started) cubre los flujos de trabajo habituales.
